HyperExecute overrides all three at run time, so these are a starting point.

Without them each user replays the journey as fast as the server answers. That is a stress test rather than a load test, and a couple of users are enough to pin a CPU.

Each user is a Chrome, so HyperExecute runs at most 4 per engine. A Chrome other than 141 also needs its own chromedriver: set webdriver.driver_path in the spec.
